#### What do we need to track per task?
- What the task is
- How do we know the task is done?
- Can it be automated?
	- If so what context it should use
- Completed or not
- What it depends on
- What project it is part of
#### What do we need to track per context?
- Is this a coding context?
	- Informational?
	- Research?
	- Summarization?
- Prompts associated with the type
- Models associated with the type
#### What do we need to track per project?
- What the project is
- Where tasks / information for the project are located
